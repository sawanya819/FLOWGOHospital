# ระบบคิวโรงพยาบาล (hp2569)

PHP 8.1+ / MySQL หรือ MariaDB · ไม่ต้องใช้ framework · ใช้งานบน XAMPP ได้ทันที

## ติดตั้ง

1. เปิด Apache และ MySQL จาก XAMPP Control Panel
2. ให้ Apache มองเห็นโฟลเดอร์นี้ เลือกทางใดทางหนึ่ง
   - ย้าย/คัดลอกโฟลเดอร์ไปไว้ที่ `C:\xampp\htdocs\hp2569` หรือ
   - เพิ่มบรรทัดต่อไปนี้ท้ายไฟล์ `C:\xampp\apache\conf\httpd.conf` แล้วรีสตาร์ต Apache
     ```apache
     Alias /hp2569 "C:/xampp/hp2569"
     <Directory "C:/xampp/hp2569">
         AllowOverride All
         Require all granted
     </Directory>
     ```
3. เปิด `http://localhost/hp2569/install/` เพื่อสร้างฐานข้อมูล `hp_queue` (หรือรัน `php install/index.php "ชื่อ รพ." "รหัส admin"`)
4. ตั้งค่าการเชื่อมต่อฐานข้อมูลได้ที่ `config.php`

บัญชีทดสอบ: `admin` (รหัสตามที่ตั้ง), `counter1`, `doc_med`, `doc_ped`, `doc_den` (รหัส `1234`)
HN ทดสอบ: `1`–`10` (ระบบเติม 0 ให้เป็น 9 หลักเอง) วันเกิดดูได้ในตาราง `his_patient`
เช่น HN `3` เกิด 2 พ.ย. 2559, HN `9` เกิด 14 ก.พ. 2543

## เชื่อมฐานข้อมูล HN ของโรงพยาบาล

แก้ `config.php` ส่วน `'his'` โดยระบุ `dsn/user/pass` ของ HIS และแก้ SQL 2 คำสั่ง
(`sql_patient`, `sql_history`) ให้คืนชื่อคอลัมน์ตามที่กำหนด ในไฟล์มีตัวอย่างสำหรับ HOSxP
ระบบคิวอ่านข้อมูลจาก HIS อย่างเดียว ไม่เขียนกลับ ควรใช้บัญชีฐานข้อมูลที่มีสิทธิ์อ่านอย่างเดียว

## หน้าจอ

| URL | ผู้ใช้ | หน้าที่ |
|---|---|---|
| `patient/login.php` | ผู้ป่วย | เข้าสู่ระบบด้วย HN + วันเกิด |
| `patient/index.php` | ผู้ป่วย | หน้าสถานะคิว, จองคิว, ยกเลิกคิว |
| `patient/history.php` | ผู้ป่วย | ประวัติการรักษา (จาก HIS) และประวัติการใช้คิว |
| `kiosk.php` | ตู้รับบัตรคิว | กรอก HN → เลือกแผนก → พิมพ์บัตรคิว (มี QR) / ยืนยันตัวผู้ที่จองออนไลน์ |
| `counter.php` | เจ้าหน้าที่ต้อนรับ | ออกบัตรคิว, ยืนยันลงทะเบียน, นำคิวที่เลยกลับเข้าคิว, ปิดขั้นตอนรับยา/ชำระเงิน |
| `room.php` | แพทย์/พยาบาล | เรียกคิวถัดไป, เรียกซ้ำ, ส่งรับยา, ข้ามคิว, เรียกคิวที่ระบุ |
| `display.php?dept=1,2` | จอทีวี | คิวที่กำลังเรียก + เสียงประกาศภาษาไทย (กดปุ่ม "เปิดเสียงประกาศ" หนึ่งครั้ง) |
| `admin/` | ผู้ดูแลระบบ | รายงานสถิติ + ส่งออก CSV, จัดการแผนก, ผู้ใช้, ตั้งค่า |

## ขั้นตอนของคิว

```
ลงทะเบียน (1) → รอพบแพทย์ (2) → พบแพทย์ (3) → รับยา/ชำระเงิน (4) → เสร็จสิ้น
 registered       waiting          serving        pharmacy            done
```

- รับบัตรที่ตู้หรือเคาน์เตอร์ ระบบถือว่าลงทะเบียนแล้ว คิวจะเริ่มที่ขั้นตอนที่ 2 ทันที
- ถ้าจองออนไลน์ คิวจะอยู่ที่ขั้นตอนที่ 1 จนกว่าผู้ป่วยจะยืนยันตัวที่ตู้หรือเคาน์เตอร์
- ลำดับคิวนับตามเวลาที่ยืนยันตัว
- เวลานับถอยหลังในขั้นตอนที่ 2 คำนวณจาก (จำนวนคิวก่อนหน้า ÷ จำนวนห้องที่กำลังตรวจ) × เวลาตรวจเฉลี่ย บวกเวลาที่ห้องตรวจที่จะว่างเร็วที่สุดยังต้องใช้อีก
- เวลาตรวจเฉลี่ยใช้ค่าจริงจาก 10 รายล่าสุดของวันนั้น ถ้าวันนั้นตรวจไปแล้วไม่ถึง 3 ราย จะใช้ค่าที่ตั้งไว้ในแผนก
- การแจ้งเตือนมีเสียง สั่น และ Browser Notification จะดังเมื่อเหลือคิวไม่เกินค่าที่ตั้งไว้ (ค่าเริ่มต้น 3 คิว) เมื่อถูกเรียก/เรียกซ้ำ และเมื่อถูกส่งไปรับยา

## หมายเหตุ

- หน้าจอทุกหน้าอัปเดตตัวเองโดยดึงข้อมูลใหม่ทุก 3–5 วินาที ไม่ต้องติดตั้ง WebSocket server
- Browser Notification บนมือถือต้องใช้ HTTPS ถ้าเปิดผ่าน HTTP จะเหลือแค่เสียงกับแถบแจ้งเตือนบนหน้าจอ
- กราฟรายงานและ QR บนบัตรคิวโหลดไลบรารีจาก cdnjs ถ้าเครื่องในโรงพยาบาลไม่มีอินเทอร์เน็ต ให้ดาวน์โหลดไฟล์มาไว้ใน `assets/` แล้วแก้ลิงก์
- ถ้าต้องการติดตั้งใหม่ ให้ลบ `install/install.lock` ก่อน
